        PROGRAM  ≡  Input → Instructions → Output

    2. SYMBOLIC FORMALIZATION — the plan must be formalizable as a symbolic

         • Each step is a Hoare triple {P} C {Q} (partial correctness).
         • The step sequence is a Hoare sequential composition proof:
               {P_1} C_1 {Q_1} ; {P_2} C_2 {Q_2} ; … ; {P_n} C_n {Q_n}
           where Q_i ⊨ P_{i+1} for all i.
         • The plan's input corresponds to P_1 and its output to Q_n.
